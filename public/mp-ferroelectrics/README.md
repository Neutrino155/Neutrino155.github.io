# Joint MP ferroelectrics explorer

This folder is a static GitHub Pages deployment bundle. It can be copied into a directory of a personal GitHub Pages site; all links and data requests are relative to this folder. No backend or build step is needed after export.

The explorer contains results for 765 processed inputs, including model-derived P–N–−P branch samples and per-image properties. It omits the source CIF/XYZ files and benchmark validation IDs. Source run artifacts remain outside this bundle.
